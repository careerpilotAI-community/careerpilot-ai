# Support

CareerPilot AI is an early-stage project maintained by its repository owner.

## Where to ask

- **Feature ideas and product suggestions:** open an issue using the [feature request template](.github/ISSUE_TEMPLATE/feature_request.yml).
- **Reproducible bugs:** open an issue using the [bug report template](.github/ISSUE_TEMPLATE/bug_report.yml).
- **General project questions:** open an issue with a clear title and enough context to answer it.
- **Security vulnerabilities:** do not use public Issues. Follow the private reporting instructions in [SECURITY.md](SECURITY.md).
- **Permission or licensing requests:** contact the repository owner through the GitHub profile for the `careerpilotAI-community` account. Obtain express written permission before copying, modifying, redistributing, or otherwise reusing project materials.

## Before asking

1. Check existing Issues and the README.
2. Include relevant version, environment, and reproduction details.
3. Use sample or synthetic data only.
4. Never share passwords, API keys, access tokens, personal data, employer information, or confidential material.

## Response expectations

This is a community project and support is provided on a best-effort basis. There is no guaranteed response or resolution time. CareerPilot AI does not currently provide paid support or service-level agreements.
