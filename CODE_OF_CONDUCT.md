# Community Code of Conduct

## Our commitment

CareerPilot AI welcomes respectful discussion from people with different backgrounds, experience levels, and perspectives. This repository is public for people to review the project and suggest improvements.

## Expected behaviour

- Be respectful, constructive, and considerate.
- Focus feedback on the idea or technical issue, not the person.
- Explain disagreements calmly and assume good faith.
- Respect privacy and do not publish another person's personal or confidential information.
- Keep discussions relevant to CareerPilot AI.
- Provide actionable, relevant feedback.

## Unacceptable behaviour

- Harassment, threats, intimidation, discrimination, or personal attacks.
- Hate speech or deliberately humiliating behaviour.
- Publishing private information, credentials, tokens, or confidential material.
- Spam, scams, malicious links, malware, or intentionally disruptive conduct.
- Using Issues or Discussions to solicit unauthorized access or promote unlawful activity.
- Posting exploit details or instructions that could put users or systems at risk in public discussions.

## Project participation

- Use GitHub Issues for suggestions and non-sensitive bug reports.
- Follow [CONTRIBUTING.md](CONTRIBUTING.md).
- Public visibility does not grant permission to copy, modify, redistribute, or reuse project materials.
- Pull requests and code contributions require prior written permission from the repository owner. Unapproved submissions may be closed without merging.

## Reporting

If you experience or observe unacceptable behaviour, contact the repository owner privately through the GitHub profile for the `careerpilotAI-community` account. For security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead. Do not publish exploitable details in public Issues.

The repository owner may edit, close, or remove discussions and may block accounts that violate this policy, subject to GitHub's platform rules.

## Scope

This policy applies to interactions in this repository, including Issues, Discussions, pull requests, and other project spaces managed by the repository owner.

## Enforcement

The repository owner will review reports and decide on proportionate action. The project is maintained on a best-effort basis; no response time is guaranteed.
