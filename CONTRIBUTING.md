# Suggesting improvements

Thank you for your interest in CareerPilot AI.

## Suggestions and bug reports

Suggestions are welcome through GitHub Issues.

1. Search existing Issues before opening a new one.
2. Use a clear, descriptive title.
3. Explain the problem or proposed improvement.
4. Describe the expected benefit and include safe examples where useful.
5. Never include passwords, API keys, access tokens, personal data, or confidential information.

## Code contributions

Pull requests and code contributions are not currently accepted unless the repository owner has given prior written permission.

The repository is public for viewing and discussion, but its contents are not licensed for copying, modification, redistribution, or derivative use. Public access does not grant those permissions.

Submitting an idea does not automatically transfer ownership of your original work. If the project owner wants to adopt a contribution, any required permission will be agreed in writing first.
