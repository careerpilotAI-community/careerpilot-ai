# Security Policy

## Reporting a vulnerability

Please do not publish exploitable vulnerability details, credentials, tokens, private user data, or attack instructions in public GitHub Issues.

If **Private vulnerability reporting** is enabled for this repository, use the repository's Security tab to submit a private report. If it is not enabled, contact the repository owner through their GitHub profile and request a private reporting channel. Do not include sensitive exploit details in a public message.

## What to include

- A short description of the affected component.
- Potential impact.
- Reproduction steps using test data only.
- A suggested mitigation, if known.

## Responsible testing

Do not access other users' data, disrupt services, or perform destructive testing. Test only systems for which you have explicit authorization.

This is an early-stage project maintained by its repository owner. A response or remediation timeline is not guaranteed.
